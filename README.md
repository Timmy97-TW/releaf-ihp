# ReLeaf IHP draft

A standalone staging copy of the **Integrated Human Practices** page for the
ReLeaf wiki (GEMS Taiwan, iGEM 2026). It carries the wiki's own stylesheets and
scripts so the page looks here exactly as it will look in place.

```
human-practices/index.html      the page
human-practices/ihp.css|js      this page's styles and behaviours
human-practices/evomap*         the interactive Project Evolution Map
assets/                         copied from the main wiki (tokens, nav, page, fonts)
assets/img/human-practices/     photographs, scaled for the web and re-encoded
tools/build_images.py           the scaling script; sources live in the main repo
```

When the page is signed off, `human-practices/` and
`assets/img/human-practices/` move into the main wiki repo unchanged.

Photographs are the team's own. Every image here was scaled and re-encoded and
nothing else was done to it.
